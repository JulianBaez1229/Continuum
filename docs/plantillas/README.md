# Plantillas

| Plantilla | Para qué | Destino de la copia |
|---|---|---|
| [plantilla-procedimiento.md](plantilla-procedimiento.md) | Documentar un procedimiento médico del catálogo | `catalogos/procedimientos/<ESP>/<codigo>.md` |
| [plantilla-especialidad.md](plantilla-especialidad.md) | Dar de alta una especialidad completa | `catalogos/especialidades/<ESP>.md` |
| [plantilla-formulario-clinico.md](plantilla-formulario-clinico.md) | Formularios (PHQ-9, EVA…) y plantillas de nota | `catalogos/formularios/` o `catalogos/plantillas-nota/` |
| [plantilla-solicitud-de-cambio.md](plantilla-solicitud-de-cambio.md) | Proponer cualquier cambio a la documentación | `cambios/SC-<nnn>-<titulo>.md` |
| [plantilla-modulo.md](plantilla-modulo.md) | Crear un módulo nuevo (31, 32…) | `modulos/<nn>-<nombre>.md` |
| [plantilla-adr.md](plantilla-adr.md) | Registrar una decisión de arquitectura | `adr/ADR-<nnn>-<titulo>.md` |

Las carpetas `cambios/`, `adr/`, `catalogos/especialidades/`, `catalogos/formularios/` y `catalogos/plantillas-nota/` se crean cuando se agregue el primer archivo.
